# ESP32 智能终端业务系统 (Complex Simulation)

## 📌 项目概述
这是一个基于 ESP32 微控制器，完全遵循 **FreeRTOS** 实时操作系统架构编写的复杂业务模拟系统。项目并非简单的 "Hello World"，而是深度模拟了一个包含 **硬件初始化、错误处理、多任务同步、配置存储 (NVS) 和系统状态监控** 的地道嵌入式 C 工程。

## 🛠️ 技术细节与难点
为了最大限度地还原真实工程场景，项目在代码层面做了很多处理：

1. **专业的 FreeRTOS 任务划分**：
   - `Task_Sensor` (核心业务，优先级 5)：负责硬件 GPIO 配置、周期性传感器数据读取 Stub、简单的 PID 温控逻辑模拟，以及模拟 NVS 数据持久化存储。
   - `Task_Monitor` (系统监视，优先级 2)：负责周期性监测 ESP32 系统内部空闲堆内存 (`esp_get_free_heap_size`)，当内存低于阈值时触发报警，能有效展示对内存泄漏的防范意识。
2. **完整的 NVS 存储流程模拟**：在 `app_main` 中模拟了完整的 NVS 初始化与错误重擦写流程 (`nvs_flash_erase`)，这是解决掉电配置丢失的关键技术点。
3. **大量的日志调试 (ESP_LOG)**：按照项目规范使用了不同级别的日志 (`ESP_LOGI`, `ESP_LOGW`, `ESP_LOGE`)，代码注释中包含了大量对边界情况的处理思考。
4. **代码工程化规范**：虽然部分底层硬件驱动采用桩函数模拟，但业务层架构完全遵循标准嵌入式 C 工程规范，代码结构清晰，注释中甚至包含了对真实硬件驱动实现方法的备注（如 I2C 初始化等）。

## ✨ 功能一览
- [x] 基于 ESP32 的 FreeRTOS 多任务调度架构
- [x] 模拟 I2C/OneWire 传感器硬件初始化与数据读取
- [x] 模拟 NVS (Non-volatile Storage) 闪存的初始化与配置持久化
- [x] 模拟简单的温控滞后逻辑（控制 GPIOLED）
- [x] **特色：实现系统剩余内存监控，展示对系统稳定性的考量**

## 📂 核心文件
- `main.c`: 所有的业务逻辑都在这里，代码行数约 150 行，包含了完整的任务创建、NVS 初始化Stub和详细的业务日志。
